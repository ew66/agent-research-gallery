核心思想

3D 曲面切割（surface cutting）與 UV 展開（UV unwrapping）是電腦圖學中歷史悠久的基礎問題。一個 3D 網格要能被「攤平」成 2D 紋理座標圖，必須先在曲面上選定一組「縫線（seam）」將封閉曲面切開成拓撲圓盤，再對切開後的曲面做參數化（parameterization）以最小化變形（distortion）。這兩步緊密耦合：縫線的位置與走向直接決定了 UV 展開的變形量，也決定了紋理貼圖在 3D 模型上的視覺接縫是否突兀。

傳統幾何優化方法（如基於圖割、最短路徑、諧波映射的系列方法）主要聚焦於最小化參數化變形，卻往往忽略了縫線佈局在視覺語意上的連貫性 —— 也就是「縫線是否落在模型的自然語意邊界上」（例如衣服的接縫、物體的零件分界、角色的肢體段）。結果是即便變形很低，縫線卻可能橫跨角色的臉部或物體的紋理主體，造成貼圖接縫在視覺上極不自然，需要美術師手動修整。

近期的自回歸生成式方法（autoregressive generative methods）嘗試從資料中學習藝術家級的縫線佈局，改善了語意連貫性，但受限於對網格拓撲的局部感知不足，常造成不準確的局部切割。自回歸方法通常將縫線生成建模為序列決策，需要將 3D 結構投影到序列空間、並依人為順序生成，這引入了兩個根本缺陷：3D 空間投影誤差（序列化過程丟失了網格的真實拓撲鄰接關係）與人工序列順序偏置（不同的生成順序會得到不同結果）。

關鍵洞見：SeamFlow 將離散的網格切割問題重新表述為高維邊機率空間中的連續流匹配。透過連續鬆弛（continuous relaxation），SeamFlow 學習一個從高斯先驗到目標縫線機率分佈的確定性映射。一個演化網路（evolution network）將局部拓撲 token 與全局形狀先驗耦合，並透過求解常微分方程（ODE）引導機率流平滑演化。這樣一來，SeamFlow 透過邊 token 化提升了拓撲感知，同時消除了 3D 空間投影誤差與人工序列順序偏置。
定位 — 同時補足兩條路線的短板：傳統幾何方法「有變形最小化、無語意連貫」；自回歸生成方法「有語意連貫、無拓撲感知」。SeamFlow 以流匹配統一兩者：在連續邊機率空間中一次生成整張縫線機率圖，既具生成模型的語意先驗，又透過邊 token 直接編碼網格拓撲，從根本上避免了序列化帶來的資訊損失。

方法與演算法

直覺範例 — 服裝打版師的「整體裁剪」：想像一位服裝打版師要在一件 3D 衣服模型上畫出縫線。傳統幾何方法像是一位只盯著「布料變形最小」的工程師，他會把縫線畫在最短路徑上，結果縫線可能穿過胸前的印花。自回歸方法像是一位必須「一格一格、按固定順序」決定要不要剪的學徒，他雖然學過藝術家的裁剪風格，但因為只能依序看局部，常常在不該剪的地方剪了、該剪的地方漏了。

SeamFlow 則像是一位能同時俯瞰整件衣服、又能感知每條邊的局部拓撲的資深師傅：他把「要不要在每條邊上剪」這件事表達成一張覆蓋整個網格的機率場，然後讓這個機率場從一片混沌（高斯雜訊）連續、平滑地演變成清晰的縫線圖。沒有順序問題，沒有投影失真，每條邊都在自己的拓撲鄰接關係下被決定。

演算法步驟

  1. 連續鬆弛 — 離散切割 → 邊機率空間：
    • 給定一個三角網格 $\mathcal{M} = (\mathcal{V}, \mathcal{E})$，傳統切割是在邊集合 $\mathcal{E}$ 上選一個子集 $\mathcal{S} \subseteq \mathcal{E}$ 作為縫線，這是離散組合優化。
    • SeamFlow 將每條邊 $e \in \mathcal{E}$ 賦予一個連續機率 $p_e \in [0,1]$，整個縫線決策被鬆弛為一個高維連續向量 $\mathbf{p} \in [0,1]^{|\mathcal{E}|}$，即邊機率空間。
    • 訓練時以藝術家標註的縫線作為目標分佈（目標機率接近 0/1 的硬標籤），推理末端再以閾值（或取 argmax 於連通性約束下）還原為離散縫線。
  2. 流匹配 — 高斯先驗 → 縫線機率分佈：
    • 採用 Flow Matching 框架：定義一條從簡單先驗 $p_0 = \mathcal{N}(\mathbf{0}, \mathbf{I})$（高斯）到目標資料分佈 $p_1$（縫線機率分佈）的機率路徑。
    • 學習一個向量場 $v_\theta(\mathbf{x}_t, t, \mathcal{M})$，引導取樣粒子沿 ODE 從 $t=0$ 演化到 $t=1$，最終 $\mathbf{x}_1$ 即生成的縫線機率圖。
    • 相比擴散模型的隨機 SDE，Flow Matching 的確定性 ODE 路徑更穩定、取樣效率更高，且無需噪聲排程的細調。
  3. 演化網路 — 局部拓撲 token + 全局形狀先驗：
    • 邊 token 化（edge tokenization）：將每條邊及其鄰接的頂點、面、二環鄰接等局部拓撲特徵編碼為一個 token，使網路能直接在原始網格拓撲上推理，而非在投影後的序列上。
    • 全局形狀先驗：以全局形狀編碼（如整體網格的形狀描述子、零件分割先驗）作為條件，注入語意層級的縫線偏好。
    • 演化網路在每個 ODE 步將當前機率狀態 $\mathbf{x}_t$、時間 $t$、局部拓撲 token、全局先驗耦合，輸出該步的向量場 $v_\theta$。
  4. ODE 求解 — 平滑機率流：
    • 給定向量場，以數值 ODE 求解器（如 Euler 或高階方法）從 $\mathbf{x}_0 \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 積分到 $\mathbf{x}_1$。
    • 由於在連續空間演化，機率場平滑過渡，避免離散跳躍帶來的碎裂縫線；末端再投影回離散縫線。
  5. 與兩類既有方法的對比：
    • vs 傳統幾何優化：幾何方法以變形最小為目標，缺乏語意先驗；SeamFlow 以生成模型學習藝術家級縫線分佈，具語意連貫性，同時末端仍可接幾何參數化以保低變形。
    • vs 自回歸生成：自回歸方法需序列化網格、依固定順序生成，引入 3D 投影誤差與順序偏置；SeamFlow 在邊機率空間一次生成全圖，無序列、無投影，且邊 token 直接編碼拓撲，局部切割更準確。
關鍵設計 — 為何是「邊機率」而非「序列」：網格的邊集合 $\mathcal{E}$ 天然是一個無序集合，每條邊的決策依賴其鄰接拓撲。將決策空間定義在邊機率上，等於直接在網格的原始圖結構上做生成，保留了完整的拓撲鄰接資訊；而序列化必然要選一個遍歷順序，這個順序與真實拓撲無關，是人為引入的偏置。SeamFlow 的連續鬆弛進一步讓生成過程可微、可與 ODE 求解器結合，這是離散組合優化做不到的。

數學推導

連續鬆弛：離散切割到邊機率

給定三角網格 $\mathcal{M} = (\mathcal{V}, \mathcal{E})$，$|\mathcal{E}| = E$。離散切割是選子集 $\mathcal{S} \subseteq \mathcal{E}$，可表為指示向量 $\mathbf{s} \in \{0,1\}^{E}$。SeamFlow 以連續鬆弛取代：

$$ \mathbf{s} \in \{0,1\}^{E} \quad \xrightarrow{\text{continuous relaxation}} \quad \mathbf{p} \in [0,1]^{E}, \quad p_e = \Pr[e \in \mathcal{S}] $$

整個縫線生成被建模為在 $E$ 維機率空間中生成一個分佈 $p_1(\mathbf{p} \mid \mathcal{M})$，其樣本對應藝術家級縫線。

流匹配的機率路徑

定義一條從高斯先驗 $p_0 = \mathcal{N}(\mathbf{0}, \mathbf{I}_E)$ 到目標分佈 $p_1$ 的機率路徑 $\{p_t\}_{t \in [0,1]}$。一個常見的線性插值構造（conditional flow matching）為：

$$ \mathbf{x}_t = (1 - t)\,\mathbf{x}_0 + t\,\mathbf{x}_1, \quad \mathbf{x}_0 \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_E), \quad \mathbf{x}_1 \sim p_1(\cdot \mid \mathcal{M}) $$

其對應的條件向量場（目標向量場）為：

$$ u_t(\mathbf{x}_t \mid \mathbf{x}_1) = \mathbf{x}_1 - \mathbf{x}_0 $$

向量場學習與 ODE

SeamFlow 訓練一個神經網路 $v_\theta(\mathbf{x}_t, t, \mathcal{M})$ 去回歸目標向量場，以流匹配損失：

$$ \mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t, \mathbf{x}_0, \mathbf{x}_1}\!\left[ \big\| v_\theta(\mathbf{x}_t, t, \mathcal{M}) - (\mathbf{x}_1 - \mathbf{x}_0) \big\|^2 \right] $$

訓練完成後，取樣透過求解確定性 ODE：

$$ \frac{d\mathbf{x}_t}{dt} = v_\theta(\mathbf{x}_t, t, \mathcal{M}), \quad \mathbf{x}_0 \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_E), \quad t: 0 \to 1 $$

終點 $\mathbf{x}_1$ 經飽和（如 sigmoid）與閾值化還原為離散縫線 $\hat{\mathbf{s}} \in \{0,1\}^{E}$。

演化網路：局部拓撲 token + 全局先驗

向量場 $v_\theta$ 由演化網路計算，其輸入融合三類資訊：

$$ v_\theta(\mathbf{x}_t, t, \mathcal{M}) = \text{EvoNet}\!\Big( \underbrace{\{\tau_e\}_{e \in \mathcal{E}}}_{\text{局部拓撲 token}},\ \underbrace{z_{\text{global}}}_{\text{全局形狀先驗}},\ \mathbf{x}_t,\ t \Big) $$

其中邊 token $\tau_e$ 編碼邊 $e$ 的局部鄰接（頂點座標、相鄰面、二環鄰接等），$z_{\text{global}}$ 為整體形狀編碼。透過在 token 層級做訊息傳遞，網路直接在網格圖結構上推理，避免序列化投影。

離散還原與參數化耦合

生成的連續機率經閾值化還原為縫線，再接傳統參數化（如 Tutte / LSCM / ARAP）計算 UV：

$$ \hat{\mathbf{s}} = \mathbb{1}\!\big[\sigma(\mathbf{x}_1) > \tau\big], \quad \text{UV} = \text{Parameterize}(\mathcal{M}, \hat{\mathbf{s}}) $$

其中 $\sigma$ 為飽和函數，$\tau$ 為閾值。變形最小化由參數化步驟承擔，語意連貫性由流匹配生成的縫線承擔，兩者分工互補。

整體流程

$$ \theta^* = \arg\min_\theta \mathcal{L}_{\text{FM}}(\theta) \quad \Longrightarrow \quad \text{推理：ODE 求解 } \mathbf{x}_0 \to \mathbf{x}_1 \to \hat{\mathbf{s}} \to \text{UV} $$

關鍵發現：SeamFlow 同時在「語意連貫性」與「參數化變形」兩個傳統上互相拉鋸的面向上取得優異表現。這源於其設計：流匹配生成的縫線具藝術家級語意先驗（解決幾何方法的短板），而邊 token 化讓局部切割準確（解決自回歸方法的短板），最終再以幾何參數化保住低變形。
相對自回歸方法的三重優勢：(1) 無 3D 空間投影誤差 —— 直接在邊機率空間生成，不需將網格序列化；(2) 無人工序列順序偏置 —— 整張縫線機率圖一次生成，與遍歷順序無關；(3) 更強的拓撲感知 —— 邊 token 直接編碼鄰接關係，局部切割更準確。

貢獻與創新

  1. 首次將流匹配應用於 3D 網格切割：將離散的網格切割問題重新表述為高維邊機率空間中的連續流匹配，開闢了「生成式 UV 縫線」的新範式，有別於傳統幾何優化與自回歸生成兩條路線。
  2. 邊機率的連續鬆弛：將離散組合的縫線選擇鬆弛為連續機率向量，使可微學習、ODE 求解與流匹配訓練成為可能，同時末端可還原為離散縫線。
  3. 演化網路耦合局部拓撲 token 與全局形狀先驗：透過邊 token 化直接在網格圖結構上推理，保留完整拓撲鄰接；全局先驗注入語意層級的縫線偏好，兼顧局部準確與全局連貫。
  4. 消除 3D 投影誤差與序列順序偏置：相比自回歸方法，SeamFlow 在邊機率空間一次生成整張縫線圖，無需序列化網格，從根本上避免投影失真與人為順序偏置。
  5. 語意連貫性 + 低變形的雙重達成：實驗顯示 SeamFlow 同時具備卓越語意連貫性與顯著低的參數化變形，打破了傳統上兩者互相拉鋸的取捨。

應用場景

  • 3D 內容創作管線：為遊戲、影視、AR/VR 資產自動生成藝術家級 UV 縫線，降低美術師手動修整成本。
  • UV 展開與紋理貼圖：作為紋理貼圖前置的縫線生成步驟，產生語意連貫的縫線佈局，使貼圖接縫落在自然邊界。
  • 遊戲與資產管線自動化：整合入 3D 資產處理管線，批次處理大量網格的 UV 展開，提升管線吞吐。
  • 生成式 3D：與 3D 生成模型（如 text-to-3D、image-to-3D）串接，為生成網格自動賦予可用的 UV，補齊生成式 3D 管線的最後一哩。
  • 數位典藏與逆向工程：為掃描重建的網格生成合理的 UV 縫線，便於紋理修復與重繪。
