1. One Editor, Many Edits: A Unified Training-Free Framework for Diverse Video Editing

EditVid — 一個無訓練框架同時支援指令引導與參考引導的多元視頻編輯，靠三個互補機制解決視頻編輯的三大難題：局部連貫、長程身份、編輯局部性

核心思想

視頻編輯（video editing）涵蓋極為多樣的編輯範式：風格轉換（style transfer）、屬性修改（attribute modification）、物件插入（object insertion）、部件級編輯（part-level editing）、主體替換（subject replacement）等。這些任務又可分為兩大引導模式：指令引導（instruction-guided）——以自然語言指令描述要做的修改；參考引導（reference-guided）——以一張參考圖提供要套用的外觀/身份。要在單一統一框架內同時高品質地支援這兩種模式與多種任務，是視頻編輯領域的開放難題。

既有方法往往只針對單一範式或單一引導模式設計，或需要針對特定任務的訓練／微調。而視頻編輯相較圖像編輯多了時序連貫性的維度，使得三個核心挑戰同時浮現：

  1. 局部連貫性（local coherence）：編輯後的視頻在相鄰幀之間必須時序一致，不能閃爍抖動；但又要允許該發生變化的區域變化。
  2. 長程身份保持（long-range identity preservation）：被保留的主體在整段視頻中身份不能漂移，尤其在劇烈運動、遮擋、視角變化下，身份需跨幀穩定。
  3. 編輯局部性（edit locality）：編輯應只作用於目標區域，不應擴散破壞背景或未編輯區域。
關鍵洞見：EditVid 提出，這三個挑戰可由三個互補的機制分別對應，且三者皆可在無訓練（training-free）前提下以即插即用方式組合進既有視頻擴散模型。三個機制是：稀疏因果記憶（sparse causal memory）保局部連貫、對應式後注意 token 注入（correspondence-based post-attention token injection）保長程身份、軟潛在混合（soft latent blending）保編輯局部性。同一套框架同時支援指令引導與參考引導，覆蓋風格轉換、屬性修改、物件插入、部件編輯、主體替換等多種任務。
定位 — 統一性來自「解耦的三機制」而非「大一統模型」：既有統一框架多走「一個大模型學所有任務」路線，需大量訓練且各任務互相遷就。EditVid 反其道：把視頻編輯的三大挑戰解耦到三個獨立機制，每個機制對應一個挑戰，組合起來即覆蓋多樣任務——這樣的統一性來自設計的完備性，而非模型容量，因而無需訓練。

方法與演算法

直覺範例 — 電影剪輯師的三件法寶：想像一位剪輯師要改一段影片裡主角的衣服顏色（指令引導），同時要保持主角臉不變、背景不動、畫面不閃。他需要三件法寶：

(1) 稀疏因果記憶像是一疊「關鍵幀的記憶卡」——他不逐幀重畫，而是選幾張關鍵幀當錨點，相鄰幀只做小幅修正，這樣畫面就連貫不閃；
(2) 對應式 token 注入像是一張「主角臉的標準照」——他在每幀該出現臉的地方，把標準照的特徵「對位」貼回去，所以臉不會隨運動漂移；
(3) 軟潛在混合像是一張「鏤空遮罩」——他只把衣服那塊換掉，背景用原片，邊界做柔化過渡，所以只改該改的、不波及無辜。

演算法步驟

  1. 基礎：視頻擴散模型 + 編輯引導：
    • 以預訓練視頻擴散模型為骨幹，輸入原視頻（或其 latent）+ 編輯條件（指令文本或參考圖）。
    • 指令引導：將編輯指令作為文本條件注入 cross-attention。
    • 參考引導：將參考圖的視覺特徵作為額外條件注入。
  2. 機制一：稀疏因果記憶（sparse causal memory）— 保局部連貫：
    • 不對每幀獨立去噪，而是維護一個稀疏的關鍵幀記憶集，相鄰幀的去噪參考記憶中的關鍵幀特徵，使時序上局部連貫。
    • 「因果」指記憶只依賴過去已生成的幀（避免未來洩漏），「稀疏」指只選關鍵幀而非全部歷史（控制成本與避免過度平滑）。
    • 作用：消除相鄰幀間的閃爍與抖動，同時允許該變化的區域變化。
  3. 機制二：對應式後注意 token 注入（correspondence-based post-attention token injection）— 保長程身份：
    • 針對要保留的主體（如人物身份），建立參考身份的 token 特徵。
    • 在擴散模型的 attention 層之後，依據跨幀的對應關係（correspondence）將身份 token 注入到當前幀對應的主體位置。
    • 「後注意」指在 self/cross-attention 計算之後施加注入，避免干擾原 attention 的語意計算；「對應式」指依據時空對應把特徵放到正確位置，使身份跨幀穩定、不隨運動漂移。
  4. 機制三：軟潛在混合（soft latent blending）— 保編輯局部性：
    • 在 latent 空間將「編輯後的 latent」與「原始 latent」依據編輯區域做軟混合：編輯區域取編輯結果，未編輯區域保留原 latent，邊界做軟過渡。
    • 「軟」指用連續權重（非硬遮罩）過渡，避免硬邊界偽影；在 latent 空間混合使融合在語意層級一致。
    • 作用：編輯只作用於目標區域，不擴散破壞背景或未編輯區域。
  5. 統一框架：兩種引導模式 × 多種任務：
    • 指令引導：文本指令驅動 cross-attention，三機制保連貫/身份/局部性，支援風格轉換、屬性修改、物件插入等。
    • 參考引導：參考圖特徵驅動外觀/身份，三機制同樣適用，支援主體替換、部件編輯等。
    • 三機制對兩種模式通用，故同一框架覆蓋多元任務。
  6. 與既有方法的對比：
    • vs 單任務訓練方法：針對單一範式訓練，遷移性差；EditVid 無訓練、統一多任務。
    • vs 既有無訓練基線：在 FiVE 基準上，EditVid 達 78.16 FiVE-Acc，相對最強無訓練基線的 58.95 大幅領先；在 IVEBench 上具競爭力。
關鍵設計 — 為何「後注意」注入而非「前注意」：在 attention 之前注入身份 token 會干擾 attention 自身的語意匹配計算，可能讓模型誤把身份特徵當成注意力查詢的內容；在 attention 之後注入，則是在語意計算完成後「疊加」身份訊號，既保留原 attention 的編輯語意，又在輸出特徵上強化身份，兩者解耦、互不干擾。

數學推導

視頻擴散的條件去噪

給定原視頻 latent $\mathbf{z}_0$，視頻擴散模型在條件 $c$（指令文本或參考特徵）下從噪聲 $\mathbf{z}_T \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 去噪：

$$ \mathbf{z}_{t-1} = \text{Denoise}_\theta(\mathbf{z}_t, t, c), \quad t = T, T\!-\!1, \dots, 1 $$

編輯後的 $\mathbf{z}_0^{\text{edit}}$ 即為結果。挑戰在於直接去噪會導致連貫性、身份、局部性問題。

機制一：稀疏因果記憶

設關鍵幀集合 $\mathcal{K} \subset \{1,\dots,F\}$（稀疏選取）。當前幀 $f$ 的去噪以記憶中的關鍵幀特徵為條件：

$$ \mathbf{z}_{t-1}^{(f)} = \text{Denoise}_\theta\!\left(\mathbf{z}_t^{(f)},\ t,\ c,\ \{\mathbf{z}_{t}^{(k)}\}_{k \in \mathcal{K},\, k < f}\right) $$

「因果」體現在只依賴 $k < f$（過去關鍵幀），「稀疏」體現在 $|\mathcal{K}| \ll F$。這使相鄰幀共享記憶錨點，局部連貫。

機制二：對應式後注意 token 注入

設參考身份的 token 特徵為 $\{\mathbf{r}_j\}$。對當前幀 $f$ 的 attention 輸出 $\mathbf{a}^{(f)}$，依時空對應 $\pi_f$（將參考位置映射到當前幀位置）在 attention 之後注入：

$$ \tilde{\mathbf{a}}^{(f)} = \mathbf{a}^{(f)} + \lambda \cdot \text{Inject}\!\left(\{\mathbf{r}_j\},\ \pi_f\right) $$

其中 $\lambda$ 為注入強度，$\text{Inject}$ 依對應 $\pi_f$ 將身份特徵放到正確時空位置。在 attention 之後施加，不干擾原 attention 的語意計算，使身份跨幀穩定。

機制三：軟潛在混合

設編輯區域的軟權重圖 $M \in [0,1]^{F \times H \times W}$（編輯區域趨近 1、未編輯趨近 0、邊界過渡）。在 latent 空間混合編輯結果與原 latent：

$$ \mathbf{z}_0^{\text{out}} = M \odot \mathbf{z}_0^{\text{edit}} + (1 - M) \odot \mathbf{z}_0^{\text{orig}} $$

軟權重使邊界平滑過渡，latent 空間混合保證語意層級一致，編輯局部於目標區域。

三機制聯合

$$ \mathbf{z}_0^{\text{out}} = \text{SoftBlend}\!\Big(\text{PostAttnInject}\!\big(\text{SparseCausal}(\mathbf{z}_T, c)\big)\Big) $$

三機制串接：稀疏因果記憶保連貫 → 後注意注入保身份 → 軟潛在混合保局部性，對指令引導與參考引導通用。

貢獻與創新

  1. 統一無訓練框架覆蓋多元視頻編輯：同一框架同時支援指令引導與參考引導，覆蓋風格轉換、屬性修改、物件插入、部件編輯、主體替換等多種任務，無需訓練。
  2. 解耦的三機制對應三大挑戰：稀疏因果記憶保局部連貫、對應式後注意 token 注入保長程身份、軟潛在混合保編輯局部性，三機制互補且對兩種引導模式通用。
  3. 對應式後注意注入：在 attention 之後依時空對應注入身份 token，解耦身份保持與語意編輯，避免干擾 attention 計算。
  4. 稀疏因果記憶：以稀疏關鍵幀為錨點、因果依賴過去，平衡時序連貫與計算成本。
  5. 無訓練下大幅領先：FiVE-Acc 78.16 vs 最強基線 58.95，使用者偏好率過半，證明設計完備性可替代訓練。

應用場景

  • 創意視頻後製：風格轉換、屬性修改、物件插入等創意編輯，無需訓練即可套用於既有視頻擴散模型。
  • 主體替換與換裝：參考引導下做人物/主體替換、服裝更換，身份跨幀保持穩定。
  • 部件級精細編輯：針對物體局部（如車輪、眼睛）做部件級修改，編輯局部於目標區域。
  • 無訓練即可部署的編輯工具：作為即插即用模組整合進視頻生成管線，降低部署門檻。
  • 多任務統一介面：為下游應用提供單一框架處理多樣編輯需求，簡化系統架構。
未來展望：三機制的解耦設計可獨立改進：更強的時空對應估計提升 token 注入精度、自適應稀疏度選擇優化因果記憶、與可編輯區域自動分割結合實現全自動局部性控制。統一框架亦可擴展至音頻驅動編輯、長視頻敘事編輯等場景。
