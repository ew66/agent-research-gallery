1. Q-VDiT: Towards Accurate Quantization and Distillation of Video-Generation Diffusion Transformers

專為視頻 DiT 設計的 PTQ 框架 —— Token-aware Quantization Estimator（TQE）補償量化誤差，Temporal Maintenance Distillation（TMD）保持時序一致性

作者Weilun Feng, Chuanguang Yang, Haotong Qin, Xiangqi Li, Yu Wang, Zhulin An, Libo Huang, Boyu Diao, Zixiang Zhao, Yongjun Xu, Michele Magno（中科院 ICT × ETH Zürich）

特性W3A6 視頻專用 時序蒸餾

核心思想

擴散 Transformer（DiT）在視頻生成任務上表現卓越，但其龐大參數量與高計算複雜度嚴重限制了在邊緣裝置上的部署。量化（Quantization）可降低位寬以減少儲存並加速推理，然而既有針對圖像生成模型的量化方法直接遷移到視頻生成任務時效果不佳。

Q-VDiT 作者系統性地識別出兩大挑戰：(1) 量化過程中的資訊損失，以及 (2) 優化目標與視頻生成獨特需求之間的錯位。為此，Q-VDiT 從「量化」與「優化」兩個視角分別提出對應方案：TQE 補償 Token 與特徵維度的量化誤差，TMD 則透過蒸餾保持幀間時空相關性，使每一幀的優化都能對齊整體視頻上下文。

關鍵洞見：視頻 DiT 與圖像 DiT 的量化本質差異在於「時序維度」。圖像量化只需考慮空間誤差，視頻量化還須維持幀間一致性。Q-VDiT 將量化誤差補償（TQE）與時序一致蒸餾（TMD）解耦處理，雙管齊下。

方法與演算法流程

與現有方法的定位

  • 圖像 DiT 量化方法（如針對 PixArt、SDXL 的 PTQ）：僅考慮空間維度誤差，直接遷移至視頻任務時幀間一致性崩壞。
  • 通用 PTQ 方法（如 SmoothQuant、BRECQ）：未針對擴散過程的時間步動態特性與視頻時序結構做適配。
  • Q-VDiT：從「量化視角」以 TQE 補償 Token/特徵維度誤差；從「優化視角」以 TMD 蒸餾保留時空相關性，使單幀優化對齊整體視頻上下文。

演算法步驟

  1. 挑戰分析：系統性分析視頻 DiT 量化的兩大挑戰 —— 量化資訊損失與優化目標錯位。
  2. TQE 構建：設計 Token-aware Quantization Estimator，在 Token 維度與特徵維度同時補償量化誤差，針對視頻長序列 Token 的分佈特性做自適應校正。
  3. TMD 設計：引入 Temporal Maintenance Distillation，以全精度教師模型引導量化學生模型，損失函數強調幀間時空相關性的保持。
  4. 聯合優化：TQE 與 TMD 聯合訓練，前者降低逐層量化誤差，後者確保端到端視頻品質。
  5. W3A6 部署：權重 3-bit、激活 6-bit 的激進配置下，仍能保持可接受的視頻品質。

數學公式與理論推導

量化誤差與 TQE 補償

設權重 $W$ 與激活 $x$ 分別量化為 $\hat{W}$、$\hat{x}$，理想輸出 $y = Wx$ 與量化輸出 $\hat{y} = \hat{W}\hat{x}$ 的誤差來自兩側。TQE 引入補償項 $\Delta_{\text{TQE}}$：

$$ \hat{y}_{\text{TQE}} = \hat{W}\hat{x} + \Delta_{\text{TQE}}(\hat{W}, \hat{x}) $$

其中 $\Delta_{\text{TQE}}$ 在 Token 維度（序列方向）與特徵維度（通道方向）分別建模量化誤差，針對視頻長序列 Token 的分佈偏離做自適應校正。

時序一致性蒸餾損失（TMD）

設全精度教師輸出特徵序列 $\{f_t^{\text{teacher}}\}_{t=1}^{T}$，量化學生輸出 $\{f_t^{\text{student}}\}_{t=1}^{T}$，TMD 損失同時考慮單幀重構與幀間時序相關：

$$ \mathcal{L}_{\text{TMD}} = \sum_{t=1}^{T} \big\| f_t^{\text{teacher}} - f_t^\text{student} \big\|^2 + \lambda \sum_{t=1}^{T-1} \big\| \Delta f_{t,t+1}^{\text{teacher}} - \Delta f_{t,t+1}^{\text{student}} \big\|^2 $$

其中 $\Delta f_{t,t+1} = f_{t+1} - f_t$ 表徵相鄰幀的時序差異，$\lambda$ 為權重超參數。第二項確保量化模型不僅單幀品質接近教師，幀間動態變化也與教師一致，從而維持視頻時序連貫性。

整體優化目標

$$ \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{task}}(\hat{y}_{\text{TQE}}, y) + \alpha \cdot \mathcal{L}_{\text{TMD}} $$

其中 $\mathcal{L}_{\text{task}}$ 為任務級重構損失（如去噪預測誤差），$\alpha$ 平衡任務損失與時序蒸餾損失。TQE 在前向傳播中補償量化誤差，TMD 在反向傳播中引導權重校正，兩者協同收斂。

W3A6 量化配置

權重 3-bit、激活 6-bit 的配置下，權重側誤差較大，TQE 的補償尤為關鍵；激活側保留 6-bit 緩解了長序列 Token 的累積誤差。整體在壓縮比與品質間取得平衡。

貢獻、創新與應用

  1. 視頻 DiT 量化挑戰系統化分析：首次明確識別視頻 DiT 量化的兩大挑戰 —— 量化資訊損失與優化目標錯位，為後續工作奠定問題框架。
  2. TQE 補償機制：提出 Token-aware Quantization Estimator，在 Token 與特徵雙維度補償量化誤差，針對視頻長序列特性做自適應校正。
  3. TMD 時序蒸餾：設計 Temporal Maintenance Distillation，透過幀間時序差異損失保持視頻時空一致性，使單幀優化對齊整體視頻上下文。
  4. W3A6 新基準：在激進的 W3A6 配置下建立 Scene Consistency 23.40 的新基準，較 SOTA 提升 1.9×。

應用場景：

  • 邊緣裝置上的視頻生成（降低儲存與計算門檻）
  • 視頻 DiT 模型的實際部署加速（如 Open-Sora、CogVideo 等視頻生成模型）
  • 視頻生成 API 服務的成本優化（更低位寬 → 更高吞吐）
  • 後續視頻量化研究的基線框架（問題定義 + 雙視角方案）
